# Model artifacts

Place the files generated by
`Experiments/lap-by-lap-s5e6-detailed-eda-baseline-lgbm.ipynb` in this
directory.

The backend artifact contract is:

| File | Required | Purpose |
| --- | --- | --- |
| `baseline_lgbm.txt` | Yes | Native LightGBM model used for inference |
| `metadata.json` | Yes | Ordered features, category mappings, versions, and model checksum |
| `smoke_test.json` | Yes | Known request and expected result for deployment verification |

Categorical values not listed in `metadata.json` must be rejected by the API.
They must not be silently assigned a new numeric code.

The three generated artifact files are intended to be committed once they have
been created and verified. Generated ZIP bundles should remain local.
